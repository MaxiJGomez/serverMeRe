# Police Assistance WebSocket Server

Node.js backend developed to support real-time communication
between mobile clients and backend services.

## Technologies

- Node.js
- JavaScript
- WebSockets
- REST
- Render

## Features

- Real-time communication through WebSockets
- Event-based message handling
- Server-side connection management
- Integration with mobile application clients

## Purpose

This project was developed as a backend component for testing
and supporting real-time communication in a mobile application.
